# SuperStore Sales Dashboard | Power BI

An interactive **Power BI sales analytics dashboard** for exploring SuperStore performance across product categories, shipping methods, locations, and time. The project includes a main sales overview and a second page focused on trends.

## What's in the report

- **KPI cards** for high-level sales performance.
- **Category and sub-category comparisons** using bar charts.
- **Ship-mode analysis** using a bar chart.
- **Geographic view** using a map.
- **Breakdowns** using donut charts and an interactive slicer.
- **Time-series views** using stacked area and line charts.

## Tools

**Power BI Desktop** · Power BI visuals · Interactive report filtering

## Open the dashboard

1. Download `SuperStore Sales Dashboard(1).pbix` from this repository.
2. Open the file using **Power BI Desktop**.
3. Explore the report pages and interact with the filters and charts.
